# 模拟图库实测步骤

100 张参考封面已全部确认并接入。本次主要检查模拟封面在实际信息流中的显示、文案与竞争效果。

## 启动新项目

```powershell
Set-Location 'D:\Work\xiaohongshu-cover-simulator-public'
npm run dev -- --port 3001
```

打开 `http://127.0.0.1:3001/`。默认使用本机 Ollama 的 `qwen3.5:4b`，先保持 Ollama 服务开启。云模型需在这个新项目自己的 `.env.local` 中配置相应 API Key，配置后重启服务。

## 分别跑两种场景

1. 填写准备发布的标题，上传两张候选封面 A/B。
2. 先选“四宫格对比”运行一次。完成后查看两版信息流大图，应各有 1 张候选图和 3 张模拟参考图。
3. 再选“纵向信息流”运行一次。完成后查看两版信息流大图，应各有 1 张候选图和 9 张模拟参考图，排列为两列五行。
4. 查看参考封面入口，检查显示是否清晰，有无不合理文案、残留水印、异常裁切或图片与标题不符。同次 A/B 应使用相同参考图与位置计划。
5. 遇到问题时保存测试 ID、测试模式、参考编号（如 `ref-088`）及截图，方便定位具体图片。

每次双封面对比执行 200 次模型判断，本地模型耗时较长；可使用页面的取消按钮停止。

## 核对范围

自动验证已覆盖 100 张图片完整性、运行时与批准版本一致性，以及两种模式的正式图片读取、抽样数量、无重复和配对合成。HTTP 回归使用本机 mock 模型响应，只验证程序流程；实际模型判断效果由此次实测观察。

原有抽样权重仅作为配置沿用，不能当作模拟封面的真实点击表现。真实发布 PK 结果可继续记录到本机“真实 PK 校准”页面。
