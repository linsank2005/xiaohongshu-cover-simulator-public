# Agent 提示词设置说明

## 文件职责

- `config/agent-prompt.md`：发送给视觉模型的唯一提示词模板。它是纯文本模板，不包含本说明文档的内容。
- `lib/agent-prompt.ts`：运行时读取模板，并把当前 Agent 的用户画像注入模板后交给现有模型调用。

## 可编辑变量

`{{AGENT_PROFILE_JSON}}`、`{{FEED_MODE_INSTRUCTIONS}}` 和 `{{CHOICE_VALUES}}` 由代码替换。前者注入当前 Agent 的完整 JSON 用户画像，后两者根据四宫格或双列纵向信息流模式注入场景说明和允许的卡片位置。修改提示词时必须保留这三个占位符。

## 输出协议

模型必须只返回 JSON，格式为 `{"choice":"A"}`。四宫格模式的 `choice` 允许值是 `A`、`B`、`C`、`D` 或 `NONE`；双列纵向信息流模式允许值是 `A` 到 `J` 或 `NONE`。

- 四宫格中 A、B、C、D 分别代表左上、右上、左下、右下；纵向信息流中 A 到 J 按从上到下、每行从左到右代表两列五行的十个位置。
- `NONE` 表示当前场景中的全部封面都没有达到自然点击阈值，是正常结果，不应为了完成任务而强行选择一张。

## 修改边界

可以直接调整浏览状态、兴趣判断、点击阈值、视觉偏好和规避因素等自然语言规则。

必须保留以下接口约束：

1. `{{AGENT_PROFILE_JSON}}` 占位符。
2. 只输出 JSON 的要求。
3. `choice` 的允许值必须与测试模式一致：四宫格为 `A`、`B`、`C`、`D`、`NONE`；纵向信息流为 `A`–`J`、`NONE`。

当前保留四宫格基线，并增加双列五行纵向信息流：四宫格为 1 张候选封面 + 3 张参考封面，纵向信息流为 1 张候选封面 + 9 张参考封面。双封面版本共用同一组参考封面、100 个 Agent 和均衡位置计划，分别完成一次模型判断。

## 生效方式

代码会在每次模型请求构造提示词时读取 `config/agent-prompt.md`。修改模板后，下一次模型请求即可使用新内容，不需要修改 `lib/simulation.ts`。

数据库中的 `promptVersion` 仍由 `lib/simulation.ts` 维护；如果一次提示词调整需要单独区分历史结果，应同步更新其中的版本号。
