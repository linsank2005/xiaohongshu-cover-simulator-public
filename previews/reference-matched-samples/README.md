# 逐张参考原稿生成的 5 张样图 · 待确认

这些图片是根据既有小红书封面作为参考，由内置 imagegen 生成的模拟示例，并非实际发布的小红书封面。

本轮采用 5 次独立生成，每次只输入一张对应的原封面，保留其主要排版、文字密度、配色和主体位置，再改写文案、重新生成画面。原图仅在原开发目录用于生成与对照；本仓库不保存原图、原图路径或原笔记链接。
